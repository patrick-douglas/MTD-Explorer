Supplementary Figure S1. Reference-matched host annotation architecture in MTD Explorer. Genome, GTF and protein resources are coordinated around the selected host reference. Protein and transcript identifiers are mapped to GTF gene identifiers, and the longest available protein for each mapped gene is retained and renamed with its gene identifier before annotation with eggNOG-mapper. GTF-derived gene metadata and matching functional assignments support construction of a custom OrgDb package with AnnotationForge, while eggNOG GO assignments independently provide a persistent reference GO master GMT. Imported GO associations in the custom OrgDb carry the electronic evidence code IEA. An existing OrgDb package can be reused when its identifiers are compatible with the selected reference. In the comparison route of the evaluated implementation, the master GMT is intersected with the gene IDs present in the analysis-specific expression input to generate compatible GO sets for ssGSEA. Preparation retains sets containing 5–500 input-matched genes; the evaluated scoring configuration additionally requires at least ten overlapping genes. Arrows indicate processing steps or resource dependencies; OrgDb is used for functional interpretation and does not generate host counts. Functional assignments are sequence-derived predictions. Quantitative coverage for the B. glabrata application is reported in Figure 2 and Supplementary Table S3.
