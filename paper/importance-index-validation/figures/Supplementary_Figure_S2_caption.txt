Supplementary Figure S2. Sensitivity of Taxon Prioritization Index (TPI) rankings to component weights and library resampling.

The analysis includes all 425 taxonomic features across 15 Biomphalaria glabrata libraries. Petroleum and blue indicate within-library relative abundance and Bracken-estimated reads, respectively. (A) Percentage of the 79 distinct normalized weight vectors retaining each number of features from the default top 20. The grid comprises the unique vectors produced by multiplying each of the four default weights by 0.5, 1 or 1.5 in all 81 joint combinations and renormalizing. (B) Retention of the full-data top 20 in 5,000 stratified bootstrap draws with five libraries per group. Solid lines indicate default weights. Dashed lines indicate the model omitting total abundance and renormalizing the three remaining weights. Each draw is compared with the full-data ranking for the same model and representation. Both representations and models used identical draws. (C) Frequency of top-20 inclusion for each feature in the original relative-abundance top 20, using default weights. Circles and diamonds give frequencies for the same features in the relative-abundance and estimated-read rankings, respectively. (D) Distribution of relative-abundance ranks for the same features. Dots mark medians and horizontal lines span the 2.5th to 97.5th percentiles among draws in which the feature was eligible. Vertical ticks show original ranks and the dashed line marks rank 20. Features absent from a draw were ineligible and contributed zero to top-20 inclusion. Components, scaling and ranks were recomputed in every draw. The frequencies and rank ranges summarize stability within this dataset. Supplementary Table S9 gives the full scenario, leave-one-out and bootstrap summaries.
